# ICE has not posted its required detention statistics

Open since October 9, 2026. From Polar Star Project, a public-interest data page; the figures are counts from public records, never about a person.

## What the records show

- ICE's last detention statistics file is dated July 20, 2026: 84 days with no new file when ICE's page was checked on October 12, 2026.
- Congress asked for this file every two weeks, so about 6 updates have been missed.
- The requirement was added in the fiscal 2020 DHS appropriations law; reporting has noted debate over whether it still binds ICE.
